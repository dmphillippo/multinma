# Beta blockers to prevent mortality after MI

Data frame containing the number of deaths in 22 trials comparing beta
blockers vs. control for preventing mortality after myocardial
infarction (Carlin 1992; Dias et al. 2011) .

## Usage

``` r
blocker
```

## Format

A data frame with 44 rows and 5 variables:

- studyn:

  numeric study ID

- trtn:

  numeric treatment code

- trtc:

  treatment name

- r:

  total number of events

- n:

  total number of individuals
