# as.stanfit

Attempt to turn an object into a
[`stanfit`](https://mc-stan.org/rstan/reference/stanfit-class.html)
object.

## Usage

``` r
as.stanfit(x, ...)

# S3 method for class 'stan_nma'
as.stanfit(x, ...)

# Default S3 method
as.stanfit(x, ...)
```

## Arguments

- x:

  an object

- ...:

  additional arguments

## Value

A [`stanfit`](https://mc-stan.org/rstan/reference/stanfit-class.html)
object.
