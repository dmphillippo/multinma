# Granulocyte transfusion in patients with neutropenia or neutrophil dysfunction

Data frame containing the number of deaths in 6 trials comparing
transfusion of granulocytes (white blood cells) to control (Stanworth et
al. 2005) . Previously used to demonstrate informative prior
distributions for the heterogeneity variance by Turner et al. (2012) .

## Usage

``` r
transfusion
```

## Format

A data frame with 12 rows and 4 variables:

- studyc:

  study name

- trtc:

  treatment name

- r:

  total number of deaths

- n:

  total number of individuals
