# Reduced dietary fat to prevent mortality

Data frame containing the number of deaths and person-years at risk in
10 trials comparing reduced fat diets vs. control (non-reduced fat diet)
for preventing mortality (Hooper et al. 2000; Dias et al. 2011) .

## Usage

``` r
dietary_fat
```

## Format

A data frame with 21 rows and 7 variables:

- studyn:

  numeric study ID

- studyc:

  study name

- trtn:

  numeric treatment code

- trtc:

  treatment name

- r:

  number of events

- n:

  number randomised

- E:

  person-years at risk
