# Print `nma_nodesplit_df` objects

Print `nma_nodesplit_df` objects

## Usage

``` r
# S3 method for class 'nma_nodesplit_df'
print(x, ...)

# S3 method for class 'nma_nodesplit'
print(x, ...)
```

## Arguments

- x:

  A
  [nma_nodesplit_df](https://dmphillippo.github.io/multinma/dev/reference/nma_nodesplit-class.md)
  object

- ...:

  Further arguments passed to
  [`print.stanfit()`](https://mc-stan.org/rstan/reference/print.stanfit.html)

## Value

`x` is returned invisibly.
